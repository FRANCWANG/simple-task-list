# Simple Task List

Create a simple to-do list app with React and TypeScript.

Features: add a task, mark a task as done, delete a task, and show how many tasks are still pending.

Put the logic in a separate file src/lib/todo.ts as pure functions:

addTask, toggleTask, removeTask, countPending.

Keep the UI clean and minimal.
